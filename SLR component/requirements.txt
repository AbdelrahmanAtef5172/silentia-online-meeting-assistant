# ---------------------------------------------------------------------------
# PyTorch install note (read this first)
# ---------------------------------------------------------------------------
# PyTorch is intentionally NOT pinned to a CUDA build below -- the correct wheel depends on
# whether you're training/running on CPU or GPU, and on your CUDA version. Install torch
# FIRST using the command for your setup, then `pip install -r requirements.txt` for
# everything else.
#
#   Google Colab (CPU or GPU runtime): torch is preinstalled -- skip this step entirely.
#
#   Local, CPU only:
#     pip install torch --index-url https://download.pytorch.org/whl/cpu
#
#   Local, NVIDIA GPU (CUDA 12.8, check your driver with `nvidia-smi` first):
#     pip install torch --index-url https://download.pytorch.org/whl/cu128
#
#   See https://pytorch.org/get-started/locally/ for the exact command for your
#   OS/CUDA version -- this changes over time and the site always has the current matrix.
#
# torch>=2.9 is required by this project (uses `weights_only=False` checkpoint loading and
# batch_first Transformer encoder layers freely available since well before 2.9; 2.9+ is
# specified defensively for the newest stable behavior as of mid-2026).
